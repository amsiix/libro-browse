This is a sample book folder structure.

To add your own books:

1. Create a folder in the books/ directory for each book
2. Add your scanned page images (JPG or PNG format) to the folder
3. Name them in sequential order: 001.jpg, 002.jpg, 003.jpg, etc.
4. Create a metadata.json file (see metadata.json in this folder as an example)

You can delete this sample-book folder once you've added your own books.

For more help, see:
- QUICKSTART.md - Guide for getting started
- BOOK_STORAGE.md - Detailed information on organizing books
- README.md - Full documentation

You can also use the add_book.py script to automatically add books:
  python add_book.py /path/to/your/book/images
